# Для Зарины — винтажная открытка

Небольшой адаптивный сайт с анимированной открывающейся открыткой.

## Файлы
- `index.html` — разметка и текст поздравления
- `style.css` — винтажный стиль и анимация
- `script.js` — открытие и закрытие открытки

## Как опубликовать через GitHub Pages
1. Создай новый публичный репозиторий на GitHub, например `zarina-birthday-card`.
2. Загрузи в корень репозитория все три файла.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. После публикации GitHub покажет адрес сайта в разделе Pages. Открой его на телефоне и проверь анимацию.

Шрифты подключаются через Google Fonts; если они недоступны, сайт использует системные шрифты.
